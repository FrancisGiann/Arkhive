# Arkhive 0.4.12 — compact Continue Reading card spacing

The 2×2 Continue Reading widget now lets portrait cover art grow with the available card height. Its progress and reading status sit above the resume arrow; a category badge appears only when space permits. Coverless and empty compact cards use the available width. The large widget and its resume behavior remain unchanged.

The 0.4.12 APK is prepared but has not been published as a GitHub release. The current downloadable preview remains 0.4.11. Once published, keep **Include preview releases** enabled in the in-app updater to see 0.4.12.
